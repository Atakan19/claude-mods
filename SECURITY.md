# Security

Mods run code inside Claude Code (hooks, tools), so please report problems privately.

Report a vulnerability through GitHub: **Security → Report a vulnerability** on this repository. Please do not open a public issue for it. You will get an answer within a few days; fixes ship as a patch release.

Supported: the latest release of each mod.

Scope: what the mods in `plugins/` do on your machine. They do not send data anywhere on their own; if you find one that does, that is a bug worth reporting.
